Why Balanced Logistic Regression?

Linear SVM achieved slightly higher accuracy (91.68%) than Balanced Logistic Regression (89.84%). However, Balanced Logistic Regression was selected as the final model because it provides strong performance while supporting predict_proba(), which allows the application to display model probability estimates for each category. It also provides a simpler and more interpretable probability-based interface for this project.
