About the Project

An NLP-based machine learning system for classifying Marathi news headlines into five categories, engineered for 100% offline local execution on a standard student laptop.

Problem Statement & Objective

The Challenge

Marathi news headlines exhibit high code-mixing with English loanwords, technical terminology, complex Devanagari inflections, and skewed class distributions. Standard tokenizers frequently mutilate Devanagari matras, degrading downstream model accuracy.

Project Goal

Build a standalone, local NLP pipeline that accepts any Marathi news headline and predicts exactly one of five discrete categories with high precision, probability distributions, and transparent term-level explainability.

Methodology & Architecture
Step 1
Unicode Normalization
NFC normalization, quotation mark standardization, Latin-script lowercasing, while retaining all Marathi inflectional suffixes.
Step 2
Devanagari Regex Tokenizer
Custom pattern [\u0900-\u097F\w]+ preventing scikit-learn's default matra-splitting bug on Devanagari vowel signs.
Step 3
Sublinear TF-IDF (1, 2)
Unigram plus bigram representations (min_df=2, 29,455 features) with logarithmic sublinear term frequency scaling.
Step 4
Balanced Logistic Regression
Multiclass linear classifier with inverse class frequency weights, producing calibrated probability distributions.
